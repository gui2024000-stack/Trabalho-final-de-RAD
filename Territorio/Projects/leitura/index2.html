o que é cada tecnologia

HTML

Linguagem de marcação para estruturar conteúdo.Pense em seções,títulos,parágrafos e formulários.

CSS

Folhas em estilo para aparência.Define cores,fontes,espaçamentos e organização visual.

JavaScript

Linguagem de programação executada no navegador.Permitindo interatividade, validações e respostas a eventos.

PHP

Linguagem de programação executada no servidor.Recebe dados dos fromulário, processa e devolve uma resposta.
